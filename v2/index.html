🔇 No Bulgarian voice yet

This device has no Bulgarian voice installed, so the game stays quiet instead of mispronouncing the words. Adding one is free and takes two minutes:

iPhone / iPad: Settings → Accessibility → Spoken Content → Voices → Bulgarian → download Daria.

Mac: System Settings → Accessibility → Read & Speak (or Spoken Content) → System voice → Manage Voices… → Bulgarian → Daria.

Android: Settings → Text-to-speech → Google Speech Services → Install voice data → Bulgarian.

Windows: Settings → Time & Language → Language → add Bulgarian with the speech pack.

Afterwards fully quit the browser, open it again and reload the game.
