# Princesa-
Raya's first game

**Princess Raya's Park Adventure** — a cute 2D browser game. A little Bulgarian princess in a folk dress explores a sunny park with her mama, collecting sparkly jewelry and finding pets (a bunny, a kitten, a baby deer and a little fox) hiding behind bushes.

- Play: open `index.html` in a browser (or the GitHub Pages link: https://markralab-ui.github.io/Princesa-/)
- Controls: arrow keys (on-screen arrows on touch devices)
